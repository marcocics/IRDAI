Sigmoid maps a raw logit to a probability-like score between 0 and 1: negative inputs approach 0, positive inputs approach 1, and 0 maps to 0.5. Class scores are independent; they do not have to sum to 1.

Applied here only during inference. During training, BCEWithLogitsLoss already incorporates sigmoid in the loss formula, so the head passes raw logits.

Bottom-up

Filter

For a 640 × 640 input, the three detection heads produce 8,400 candidate boxes per image: one at each location of their feature grids.

80² + 40² + 20² = 6,400 + 1,600 + 400 = 8,400

These are possible detections, not 8,400 objects. Many candidates describe the background or overlap around the same object.

Keep confident predictions

Each candidate receives a confidence score: objectness multiplied by its highest class score. Candidates below the chosen threshold are discarded.

Suppress duplicates

Non-maximum suppression (NMS) keeps higher-scoring boxes and suppresses strongly overlapping alternatives. It can compare boxes within each class or across all classes.

Output

The output is the list of detections that remain after filtering. Each detection includes:

  • A bounding box: the predicted object’s position and extent.
  • A class label: the predicted category, such as person or car.
  • A confidence score: objectness multiplied by the score for the predicted class.

The number of detections varies with the image and filtering thresholds. It can also be zero.

Detection heads

The detection heads turn the neck’s learned features into candidate object detections. Each head works on one of the three feature grids.

Three scales, the same task

The finer 80 × 80 grid is useful for small objects, the 40 × 40 grid for medium objects, and the coarser 20 × 20 grid for large objects. These are complementary scales, not strict size limits.

What does each head predict?

  • Box: where an object could be and how large it is.
  • Objectness: a score indicating whether an object is present.
  • Class scores: scores for categories such as person, car or bicycle.

The heads produce many candidates. The filtering stage then removes low-confidence predictions and suppresses overlapping duplicates.

Backbone · CSPDarknet

The backbone turns image pixels into learned visual features. Earlier stages capture local patterns such as edges and textures; deeper stages combine them into more complex patterns and gather information from a wider area of the image.

As features pass through the backbone, spatial grids become smaller and the number of channels grows. This trades fine spatial resolution for richer feature representations.

Focus · the entrance

Focus first rearranges each 2 × 2 pixel neighborhood into channels, preserving every value during this rearrangement. A convolution then starts extracting features on the smaller grid.
